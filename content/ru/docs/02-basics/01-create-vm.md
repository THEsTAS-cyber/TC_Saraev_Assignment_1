## Как создать новую ВМ

1. Сначала у вас должна быть активная подписка на сервис (см. [Подписки](../01-setup/02-subscription/)).
2. На главной странице сайта нажмите кнопку **VIRTUAL MACHINES** на левой панели.
   ![Main Virtual Machines](../../../en/images/Main_virtual_machines.png)
3. На странице виртуальных машин нажмите кнопку со **стрелкой вправо** ИЛИ, если вы уже создали ВМ, нажмите кнопку **NEW** в левом нижнем углу, а затем **STANDALONE VIRTUAL MACHINE**.
   ![New VM](../../../en/images/Virtual_machines_empty_new.png)
4. В открывшемся меню выберите один из двух способов создания:
   - **From Gallery**: Подробная настройка с использованием предварительно настроенных шаблонов. Лучше подходит для специфических требований. (см. [Создание ВМ из галереи](02-gallery-vm/))
   - **Quick Start**: Быстрое создание с базовыми настройками. Лучше подходит для простых ВМ. (см. [Быстрое создание ВМ](03-quick-vm/))
   ![Choose Template](../../../en/images/VM_choose_template.png)
