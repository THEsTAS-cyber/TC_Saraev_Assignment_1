      Этот глоссарий определяет ключевые термины, используемые в документации Innopolis VM.

      A#

      Аккаунт администратора Стандартная учётная запись пользователя на виртуальной машине. Она имеет полный контроль над системой. На Linux VM это обычно пользователь root. На Windows VM это пользователь Administrator.

      D#

      Панель управления Основная веб-страница, где вы управляете своими виртуальными машинами и подписками. Вы открываете её после входа в Innopolis VM.

      G#

      Галерея Каталог предварительно настроенных шаблонов виртуальных машин. Каждый шаблон включает операционную систему и, в некоторых случаях, предустановленное программное обеспечение.

      I#

      Innopolis VM Сервис, который позволяет студентам, преподавателям и сотрудникам Innopolis University создавать и управлять виртуальными машинами.

      IP-адрес Число, идентифицирующее вашу виртуальную машину в сети. Выглядит как 10.13.127.89. Вам нужен IP-адрес для подключения к VM через SSH.

      S#

      SSH-ключ Пара файлов (открытый и закрытый), которую вы используете для безопасного подключения к виртуальной машине без пароля. Открытый ключ хранится на VM. Закрытый ключ остаётся на вашем устройстве.

      SSH-клиент Программа, которая позволяет вам подключаться к виртуальной машине по протоколу SSH. Примеры: PuTTY, MobaXterm или встроенная команда ssh в macOS и Linux.

      Подписка План доступа, который определяет ваши пределы ресурсов (CPU, RAM, хранилище) в Innopolis VM. Вам нужна активная подписка для создания виртуальной машины.

      T#

      Шаблон Готовая конфигурация для виртуальной машины. Шаблон включает операционную систему и, иногда, предустановленное программное обеспечение. Вы выбираете шаблон при создании VM из галереи.

      V#

      VM Виртуальная машина. Программная эмуляция физического компьютера. После первого упоминания в тексте мы используем сокращение «VM».

      Детали VM Страница, которая показывает информацию о конкретной виртуальной машине: её статус, IP-адрес, операционную систему и дату создания.

      WebConsole Интерфейс на основе браузера, который позволяет вам подключаться к вашей виртуальной машине без установки SSH-клиента. Вы открываете его из панели управления VM, нажав CONNECT, а затем WebConsole.

      Не нашли нужный термин? Проверьте страницу Системные требования или раздел Устранение неисправностей.
