      This glossary defines the key terms used in the Innopolis VM documentation.

      A#

      Administrator account The default user account on a virtual machine. It has full control over the system. On Linux VMs, this is usually the root user. On Windows VMs, it is the Administrator user.

      D#

      Dashboard The main web page where you manage your virtual machines and subscriptions. You open it after logging in to Innopolis VM.

      G#

      Gallery A catalog of pre-configured virtual machine templates. Each template includes an operating system and, in some cases, pre-installed software.

      I#

      Innopolis VM The service that lets students, instructors, and staff of Innopolis University create and manage virtual machines.

      IP address A number that identifies your virtual machine on the network. It looks like 10.13.127.89. You need the IP address to connect to your VM via SSH.

      S#

      SSH key A pair of files (public and private) that you use to connect to a virtual machine securely, without a password. The public key is stored on the VM. The private key stays on your device.

      SSH client A program that lets you connect to a virtual machine over the SSH protocol. Examples: PuTTY, MobaXterm, or the built-in ssh command in macOS and Linux.

      Subscription An access plan that defines your resource limits (CPU, RAM, storage) within Innopolis VM. You need an active subscription to create a virtual machine.

      T#

      Template A ready-made configuration for a virtual machine. A template includes the operating system and, sometimes, pre-installed software. You choose a template when you create a VM from the gallery.

      V#

      VM Virtual machine. A software-based emulation of a physical computer. After the first mention in a text, we use the abbreviation “VM”.

      VM details The page that shows information about a specific virtual machine: its status, IP address, operating system, and creation date.

      WebConsole A browser-based interface that lets you connect to your virtual machine without installing an SSH client. You open it from the VM dashboard by clicking CONNECT and then WebConsole.

      Did not find the term you need? Check the System requirements page or the Troubleshooting section.
