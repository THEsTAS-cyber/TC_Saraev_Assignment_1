      Создание виртуальной машины

      • Как создать новую виртуальную машину
      • Как создать новую виртуальную машину через быстрый запуск

      Как создать новую виртуальную машину#

      1. Сначала у вас должна быть подписка на сервис (см. Подписки).
      2. На главной странице сайта нажмите кнопку «VIRTUAL MACHINES» в левой панели.
      3. На странице Virtual Machines нажмите кнопку со стрелкой вправо ИЛИ, если вы уже создали какие-либо виртуальные машины, нажмите кнопку «New» в левом нижнем углу и затем «STANDALONE VIRTUAL MACHINE».
      4. В открытом меню вы можете выбрать шаблон для создания виртуальной машины: быстрый запуск или из галереи.

      Как создать новую виртуальную машину через быстрый запуск#

      1. Откроется меню быстрого создания.
      2. Здесь вам нужно ввести имя вашей виртуальной машины в поле «NAME». Имя обязательно.
      3. Также выберите тип подписки — в зависимости от него вы можете выбрать разные шаблоны (операционные системы) для виртуальной машины.
      4. Затем выберите шаблон (операционную систему) для вашей виртуальной машины.
      5. Введите и подтвердите новый пароль для вашей виртуальной машины.
      6. Если вы видите красный восклицательный знак в поле «PASSWORD», условие по паролю не выполнено (см. Требования к паролю).
      7. Поле «ADMINISTRATOR ACCOUNT» может быть заполнено по умолчанию и не может быть изменено. Но в некоторых случаях от вас требуется ввести своё имя в это поле.
      8. Сохраните свой пароль, учётную запись администратора и SSH-ключ или ключ продукта, так как вы больше не сможете их увидеть.
      9. Если все поля заполнены правильно — нажмите кнопку «CREATE VM INSTANCE».
      10. Чтобы увидеть детали создания — нажмите кнопку «DETAILS».
      11. Здесь вы можете видеть прогресс создания вашей виртуальной машины.
      12. На странице Virtual Machines вы увидите свою виртуальную машину. Некоторое время её статус будет «Creating», затем он изменится на «Running».
