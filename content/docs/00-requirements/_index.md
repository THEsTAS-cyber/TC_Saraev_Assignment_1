Before you start using Innopolis VM, make sure your device and network meet these requirements.

## Browser

You access Innopolis VM through a web browser. Use one of these (or any that work with the same standards):

| Browser | Minimum version |
|---------|-----------------|
| Google Chrome | 120+ |
| Mozilla Firefox | 120+ |
| Microsoft Edge | 120+ |
| Safari | 17+ |

Older versions may not display the dashboard correctly.

## Network

- **Internet connection:** Stable broadband (at least 5 Mbps download).
- **Ports:** Outbound connections to ports 22 (SSH) and 443 (HTTPS) must be open.
- **SSO access:** You must be able to reach `sso.university.innopolis.ru` for login.

If you work from a university campus network, these ports are open by default. If you work from home and use a corporate VPN, check with your IT team.

## Hardware (for web console access)

If you connect to your VM through the browser (WebConsole), your device needs:

- **RAM:** 4 GB minimum, 8 GB recommended.
- **Screen resolution:** 1280×720 or higher.
- **JavaScript:** Enabled in your browser.

## Hardware (for SSH clients)

If you connect via PuTTY, MobaXterm, or another SSH client:

- **OS:** Windows 10/11, macOS 12+, or Linux (Ubuntu 22.04+, Debian 12+).
- **SSH client installed:** PuTTY (Windows), MobaXterm (Windows/Linux/macOS), or built-in `ssh` command (macOS/Linux).

## Account

You need an active Innopolis University account with access to Innopolis VM. If you cannot log in, contact your instructor or the IT support team.

Once your device and account meet these requirements, you can get access to Innopolis VM and create your first subscription.
