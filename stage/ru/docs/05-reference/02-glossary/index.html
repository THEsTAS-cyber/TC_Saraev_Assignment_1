      Этот глоссарий определяет ключевые термины, используемые в документации по виртуальным машинам (ВМ) Innopolis.

      В#

      ВМ (VM)
      Виртуальная машина. Программная эмуляция физического компьютера. После первого упоминания на странице мы используем аббревиатуру «ВМ».

      Веб-консоль (WebConsole)
      Веб-интерфейс на основе браузера, который позволяет подключаться к вашей ВМ без установки отдельного SSH-клиента. Вы открываете его с панели управления ВМ, нажав CONNECT, а затем WebConsole.

      Г#

      Галерея (Gallery)
      Каталог предварительно настроенных шаблонов ВМ. Каждый шаблон включает операционную систему и, в некоторых случаях, предустановленное программное обеспечение.

      Д#

      Детали ВМ (VM details)
      Страница, которая показывает информацию о конкретной ВМ: ее статус, IP-адрес, операционную систему и дату создания.

      И#

      Innopolis VM
      Сервис, который позволяет студентам, преподавателям и сотрудникам Университета Иннополис создавать и управлять виртуальными машинами.

      IP-адрес (IP address)
      Число, идентифицирующее вашу ВМ в сети. Выглядит как 10.13.127.89. Вам нужен IP-адрес для подключения к вашей ВМ через SSH.

      П#

      Панель управления (Dashboard)
      Основная веб-страница, где вы управляете своими виртуальными машинами и подписками. Вы открываете ее после входа в Innopolis VM.

      Подписка (Subscription)
      План доступа, который определяет ваши лимиты ресурсов (ЦП, ОЗУ, хранилище) в рамках Innopolis VM. Для создания ВМ вам нужна активная подписка.

      С#

      SSH-ключ (SSH key)
      Пара файлов (открытый и закрытый), которую вы используете для безопасного подключения к ВМ без пароля. Открытый ключ хранится на ВМ. Закрытый ключ остается на вашем устройстве.

      SSH-клиент (SSH client)
      Программа, которая позволяет подключаться к ВМ по протоколу SSH. Примеры: PuTTY, MobaXterm или встроенная команда ssh в macOS и Linux.

      У#

      Учетная запись администратора (Administrator account)
      Стандартная учетная запись пользователя на ВМ. Имеет полный контроль над системой. На ВМ с Linux это обычно пользователь root. На ВМ с Windows это пользователь Administrator.

      Ш#

      Шаблон (Template)
      Готовая конфигурация для ВМ. Шаблон включает операционную систему и, иногда, предустановленное программное обеспечение. Вы выбираете шаблон при создании ВМ из галереи.

      Не нашли нужный термин?
